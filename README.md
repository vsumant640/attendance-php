# Attendance Management System

## 📌 Project Overview

The Attendance Management System is a web-based application developed using PHP, MySQL, HTML, CSS, JavaScript and Bootstrap.

The system helps manage student attendance and provides an organized platform for managing attendance-related records.

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- XAMPP

## ✨ Features

- Student Management
- Attendance Management
- User Login
- Admin Dashboard
- Attendance Records
- Database Management
- Responsive Web Interface

## 📸 Project Screenshots

The project includes interfaces for:

## ⚙️ Installation & Setup

1. Install XAMPP.
2. Copy the project folder into:
   `C:\xampp\htdocs\`
3. Start Apache and MySQL from XAMPP.
4. Create the required database in MySQL.
5. Configure the database connection in the PHP configuration file.
6. Open the project in your browser:

   `http://localhost/attendance-php/`
